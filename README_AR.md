# قياسي BootARDL

مكتبة بايثون **عربية أولاً** لاختبار التكامل المشترك **ARDL بالبوتستراب**
(اختبار الحدود). تصميم أحادي المعادلة **بدون VECM**، مستوحى من حزمة `bootCT`
في R ومعاد هندسته للبحث القياسي العربي.

**المؤلف:** د. مروان رودان — **الترخيص:** GPL-3.0

**المستودع:** https://github.com/merwanroudane/bootardlarabic

---

## لماذا هذه المكتبة؟

- **واجهة ومخرجات عربية بالكامل.** الدالة الرئيسية `اختبار_ARDL_بالبوتستراب`،
  وكل عناوين النتائج والقرارات والتفسير والتقارير بالعربية. توجد واجهة إنجليزية
  مطابقة `bootstrap_ardl_test` تستدعي **نفس المحرّك المشترك**.
- **بوتستراب بدون VECM.** بدلاً من محاكاة نموذج VECM متعدّد المعادلات، تُولَّد
  التوزيعات الصفرية عبر **بوتستراب لبواقي نموذج ARDL المشروط أحادي المعادلة مع
  تثبيت المتغيرات المستقلة X**. الاستدلال **مشروط بالمتغيرات المستقلة المرصودة**.
- **ثلاث إحصائيات، توليد واحد.** تحت فرضية عدم التكامل المشترك الشاملة، تعطي
  البيانات المولّدة نفسها التوزيعات الصفرية لإحصائيات `F الكلية` و`t` (على مستوى
  المتغير التابع المتأخر) و`F للمتغيرات المستقلة`.
- **رصد التكامل المشترك الزائف/المتدهور.** يُرفع العَلَم عندما ترفض إحصائية F
  المستقلة في النموذج **المشروط** الفرضيةَ الصفرية بينما لا ترفضها في النموذج
  **غير المشروط**.
- **مستشار منهجي عربي.** تحذيرات عملية: قلّة التكرارات، صغر العينة، الارتباط
  الذاتي، الحالة المتدهورة، التنبيه إلى I(2)، …
- **تقارير RTL** بصيغ HTML و Word و Excel (و PDF اختيارياً).
- **رسوم بيانية عربية.** توزيعات البوتستراب الصفرية، رسم القرار، فحص التكامل
  الزائف، والسلاسل الزمنية — جميعها بعناوين عربية متصلة الحروف وصحيحة الاتجاه
  (RTL) وبلوحة ألوان متناسقة.

## التثبيت

```bash
pip install qiyasi-bootardl
pip install "qiyasi-bootardl[reports]"   # لتقارير Word و Excel
```

## البدء السريع

```python
from qiyasi_bootardl import اختبار_ARDL_بالبوتستراب
from qiyasi_bootardl.datasets import تحميل_بيانات_كلية

البيانات = تحميل_بيانات_كلية()
النتيجة = اختبار_ARDL_بالبوتستراب(
    البيانات,
    المتغير_التابع="الناتج",
    المتغيرات_المستقلة=["الاستثمار", "الانفتاح"],
    الحالة=3,
    أقصى_إبطاء=4,
    عدد_تكرارات_البوتستراب=2000,
    عشوائية=2024,
)
print(النتيجة.ملخص())
print(النتيجة.تفسير())
print(النتيجة.قرار().label_ar)
النتيجة.تقرير_HTML("تقرير.html")
النتيجة.تقرير_Word("تقرير.docx")
النتيجة.تقرير_Excel("تقرير.xlsx")
```

## دوال كائن النتائج

| الدالة | الوظيفة |
|--------|---------|
| `ملخص()` | نص ملخّص شامل |
| `تفسير()` | فقرة تفسير اقتصادي ومنهجي |
| `قرار(مستوى)` | القرار النهائي عند مستوى معنوية |
| `تحذيرات()` | قائمة التحذيرات المنهجية |
| `جدول_الإحصائيات()` | إحصائيات الاختبار |
| `جدول_البوتستراب()` | القيم الحرجة بالبوتستراب |
| `جدول_القيم_الاحتمالية()` | القيم الاحتمالية بالبوتستراب |
| `جدول_المعاملات(مشروط)` | معاملات النموذج |
| `جدول_حدود_PSS()` / `جدول_حدود_SMG()` | الحدود التقاربية |
| `تقرير_HTML/Word/Excel(مسار)` | تصدير التقارير |
| `رسم_توزيعات_البوتستراب(مسار)` | مدرّجات التوزيعات الصفرية الثلاثة |
| `رسم_القرار(مسار)` | أعمدة الإحصائيات مقابل القيم الحرجة |
| `رسم_التكامل_الزائف(مسار)` | مقارنة F المشروط وغير المشروط |
| `رسم_السلاسل_الزمنية(مسار)` | رسم سلاسل المتغيرات |
| `حفظ_كل_الرسوم(مجلد, بادئة)` | حفظ جميع الرسوم في مجلد |

## ملاحظات منهجية

- القيم الحرجة لاختبار PSS المضمّنة **تقاربية** للراحة فقط؛ **القرار الأساسي
  يعتمد على القيم الحرجة بالبوتستراب** لأنها دقيقة للعيّنة محل الدراسة.
- البوتستراب يُثبّت X، فالاستدلال مشروط بالمتغيرات المستقلة المرصودة (هذه هي
  مقايضة التصميم بدون VECM).
- تأكّد أن المتغيرات لا تتجاوز رتبة التكامل I(1) (لا وجود لـ I(2)) قبل الاعتماد
  على نتائج اختبار الحدود.
