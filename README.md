# qiyasi-bootardl (قياسي BootARDL)

An **Arabic-first** Python library for the **bootstrap ARDL bounds test** for
cointegration. Single-equation, **VECM-free** design. Inspired by the R package
`bootCT`, re-engineered for Arabic econometric research.

**Author:** Dr. Merwan Roudane — **License:** GPL-3.0

**Repository:** https://github.com/merwanroudane/bootardlarabic

---

## Why this library

- **Arabic-first API and output.** The primary function is
  `اختبار_ARDL_بالبوتستراب`, every result label, decision, interpretation and
  report is in Arabic. An identical English API (`bootstrap_ardl_test`) calls the
  **same shared engine**.
- **VECM-free bootstrap.** Instead of bootstrapping a multivariate VECM, the null
  distributions are generated by a **single-equation conditional ARDL residual
  bootstrap holding X fixed**. Inference is *conditional on the observed
  regressors*. This is a deliberate design choice (simpler, transparent, no
  cross-equation feedback assumptions).
- **Three statistics, one DGP.** Under the global no-cointegration null the same
  generated data yields the null distributions of `F-overall`, `t` (on the lagged
  dependent level), and `F-independent`.
- **Fake / degenerate cointegration detection.** Flags the case where the
  *conditional* F-independent rejects but the *unconditional* one does not.
- **Methodology advisor.** Arabic, actionable warnings (low replications, small
  sample, serial correlation, degenerate case, I(2) caution, …).
- **RTL reports** in HTML, Word and Excel (PDF optional).
- **Arabic visualizations.** Bootstrap null distributions, decision bar chart,
  fake-cointegration check and time-series plots — all with correctly shaped
  right-to-left Arabic labels and a cohesive colour palette.

## Quick start (English)

```python
from qiyasi_bootardl import bootstrap_ardl_test
from qiyasi_bootardl.datasets import load_macro_example

data = load_macro_example()
result = bootstrap_ardl_test(
    data, yvar="الناتج", xvar=["الاستثمار", "الانفتاح"],
    case=3, max_lag=4, n_boot=2000, random_state=2024,
)
print(result.summary())
print(result.decision_label())          # e.g. "Cointegration"
result.arabic.تقرير_HTML("report.html")  # RTL Arabic report

# Arabic-labelled plots
result.plot_distributions("dist.png")   # bootstrap null distributions
result.plot_decision("decision.png")    # observed vs critical bars
result.save_all_plots("figures")        # all plots to a folder
```

## Quick start (Arabic)

```python
from qiyasi_bootardl import اختبار_ARDL_بالبوتستراب
from qiyasi_bootardl.datasets import تحميل_بيانات_كلية

البيانات = تحميل_بيانات_كلية()
النتيجة = اختبار_ARDL_بالبوتستراب(
    البيانات, المتغير_التابع="الناتج",
    المتغيرات_المستقلة=["الاستثمار", "الانفتاح"],
    الحالة=3, أقصى_إبطاء=4, عدد_تكرارات_البوتستراب=2000, عشوائية=2024,
)
print(النتيجة.ملخص())
print(النتيجة.تفسير())
النتيجة.تقرير_HTML("تقرير.html")
```

## Methodological notes

- The embedded PSS (2001) F/t bounds are **asymptotic** convenience tables. The
  package's **primary decision basis is the bootstrap critical values**, which are
  exact for the sample at hand.
- The bootstrap holds X fixed; inference is conditional on the observed
  regressors. There is no cross-equation feedback (this is the VECM-free
  trade-off).
- Verify variables are at most I(1) (no I(2)) before relying on bounds testing.
